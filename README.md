# 沉浸式乱翻译

一个浏览器扩展（Chrome / Edge），通过多语言回译链路把网页文字翻译得面目全非，制造沉浸式“乱翻译”效果。

> 没什么用，纯好玩。

---

## 效果示例

在任意中文网页点击扩展图标，选择「开始乱翻译」，页面上的可见文字会经过以下链路回译：

```
中文 → 英文 → 芬兰语 → 越南语 → 中文
```

主链路失败时会自动降级为：中 → 英 → 芬兰语 → 日 → 中，或更保守的链路。

经过多次语言转换后，语义往往会变得离谱又搞笑。

点击「恢复原文」即可一键还原。

## 安装方式（开发模式）

1. 克隆或下载本仓库。
2. 执行构建脚本（可选）：
   ```bash
   node scripts/build.js
   ```
3. 打开 Chrome 浏览器进入 `chrome://extensions/`，或打开 Edge 浏览器进入 `edge://extensions/`。
4. 开启右上角「开发者模式」。
5. 点击「加载已解压的扩展程序」，选择本项目的 `src/` 目录（或构建后的 `dist/` 目录）。
6. 扩展图标出现在工具栏，点击即可使用。

---

## 使用说明

1. 打开任意中文网页。
2. 点击扩展图标，弹出控制面板。
3. 点击「开始乱翻译」，等待进度条完成。
4. 页面右下角会显示翻译进度。
5. 翻译完成后，可点击「恢复原文」还原。

## 百度翻译 API 配置（推荐国内网络使用）

如果你在中国大陆或 Google 翻译 API 无法访问，建议配置百度翻译 API。

### 申请密钥

1. 打开 [百度翻译开放平台](https://fanyi-api.baidu.com/)。
2. 使用百度账号登录。
3. 进入「管理控制台」→「开通服务」。
4. 选择 **标准版**（有免费额度，个人测试够用）。
5. 创建应用，获取：
   - **App ID**
   - **Secret Key**

> 标准版一般提供约 50 万字符/月的免费额度。当前主链路会调用 4 次 API（中→英、英→芬兰语、芬兰语→越南语、越南语→中），实际消耗 ≈ 原文字符数 × 4。

### 配置到插件

1. 点击扩展图标，打开 popup。
2. 点击 **「翻译设置」**。
3. 填入 **App ID** 和 **Secret Key**。
4. 点击 **保存**。
5. 刷新当前网页，点击「开始乱翻译」。

## 注意事项

- 本插件默认优先使用已配置的百度翻译 API，未配置时回退到 Google 免费翻译 API；翻译过程会把网页文字发送到对应服务器。
- 当前图标为占位图，后续会替换为正式设计。
- MVP 阶段 `content.js` 为单一内联文件；后续迁移到 Vite 时会恢复模块化结构。
- 大页面翻译可能需要几分钟（受百度 QPS=1 限制），请耐心等待进度更新。
- 翻译完成后浏览器控制台可能出现 `background port 空闲断开` 日志，这是 MV3 Service Worker 的正常生命周期，不影响功能。
- 仅供娱乐，请勿在涉及敏感信息或重要工作的页面使用。
